FreshBooks from your terminal, or from your LLM.

Log time, check receivables, invoices, unbilled time, revenue and expenses with fb. Or register fb mcp with Claude, Codex or another MCP client and just ask.

No tunnel needed to log in. Register one redirect URI on your FreshBooks app and you're set.

terminal
# to your default project and service
$ fb time add --hours 2
# what you usually log, and where
$ fb time habits
$ fb invoices list --status overdue
$ fb reports ar-aging

What you can do

  • Log time without the browser

    fb time add adds to today's entry for the same project and service, or creates one. Aliases and defaults keep it to a few keystrokes.

  • See what's owed

    Invoices by status, AR aging, per-client receivables and unbilled time, as tables or --json.

  • Run the numbers

    Revenue, expense summaries, profit and loss, billable rates and utilization, with CSV export where it helps.

  • Ask an LLM

    fb mcp is an MCP server for Claude Code, Claude Desktop, Codex and others. It can read your books and log time, and it explains its errors.

Set up in about fifteen minutes

You'll need Python 3.11+, uv, and a FreshBooks account. Most of the time goes to creating the FreshBooks app.

  1. Install

    git clone https://github.com/mysticcoders/freshbooks-tools.git
cd freshbooks-tools
uv sync

  2. Create a FreshBooks app

    Open the FreshBooks developer page and click Create App. Any name, website and description will do. Enable the scopes listed in Configuration › OAuth scopes.

  3. Set the redirect URI

    Add this as the app's redirect URI. It's the default in fb, so there's nothing else to configure.

    https://freshbooks-tools.wecodefire.com/callback

    FreshBooks requires HTTPS and rejects localhost. This address hands the login back to fb on your machine. See how.

  4. Add your credentials

    cp .env.example .env
# then set these two from your FreshBooks app
FRESHBOOKS_CLIENT_ID=<client id>
FRESHBOOKS_CLIENT_SECRET=<client secret>

  5. Log in

    uv run fb auth login
uv run fb auth status

    Your browser opens. Approve the app and the terminal reports success. You only do this once; fb refreshes its token on its own after that.

  6. Use it anywhere, and connect your LLM

    uv tool install .
fb auth setup .env     # copies credentials where the installed fb finds them
claude mcp add --scope user freshbooks -- fb mcp

    Claude Desktop, Codex and agents without MCP are covered in Connect an LLM.

How the callback works

When you log in, fb listens on 127.0.0.1:8374 for FreshBooks to send back an authorization code. FreshBooks will only redirect to an HTTPS address, and it rejects localhost, so it can't reach that listener directly. This site's /callback sits in between.

  • It never sees your secret

    Your client secret stays in your .env. Only fb uses it, talking straight to FreshBooks.

  • A code alone is useless

    The authorization code passes through in the URL, but it can't be exchanged without your secret, expires quickly and works once.

  • Nothing is kept

    The relay is a single redirect. It stores nothing, logging is off, and responses are no-store and no-referrer.

  • Forged callbacks are refused

    Each login sends a random state value, and fb rejects any callback that doesn't return it.

It's a few dozen lines: read the source.

Prefer to do it yourself?

The hosted callback is a convenience, not a requirement. Point FRESHBOOKS_REDIRECT_URI anywhere you control.

Host your own relay

Deploy the same Worker to a hostname on your Cloudflare account. Needs Node.js 22.18+ and the cf CLI.

cd relay
# set domains in cloudflare.config.ts to your host
npm install
cf deploy

Then in .env, and as the app's redirect URI:

FRESHBOOKS_REDIRECT_URI=https://<your-host>/callback

Use ngrok or another tunnel

Run a tunnel to the login listener while you log in, and stop it afterwards.

ngrok http 8374

Then in .env, and as the app's redirect URI:

FRESHBOOKS_REDIRECT_URI=https://<ngrok-host>/callback
# only if the tunnel forwards somewhere other than 8374
FRESHBOOKS_LOCAL_PORT=<port>

Free ngrok URLs change on every restart, so you'll update both each time you log in.
